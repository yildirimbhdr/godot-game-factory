**What happened:** The first store-name proposals for Slide Buddies contained "Ice" and "Penguin" and "Buz"/"Penguen". The game has three worlds (ice, ember, space) and more characters (cat, ninja), so the name would have been wrong after the next world.
**Root cause:** Name ideation looked only at the first level theme and the search keywords, not at the GDD roadmap.
**Rule:** The store name and subtitle carry the mechanic and genre ("Slide", "Maze Puzzle"); theme and character words (ice, penguin, cave, desert) go into the 100-byte keyword field, which can change with every release. Read the GDD world list before proposing names, and give an EN and a TR variant.
