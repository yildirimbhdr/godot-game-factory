**What happened:** the user shared a screenshot of an unscrew puzzle (a level-32 screen). I took the tap/jar/tray mechanic and built 3 large plates with no level map. The user's verdict: not a level game, pieces far too big and loose, no pieces forming a whole, no real contact physics.
**Rule:** extract structure, density, layering and figure-building from reference images too (checklist in `skills/physics-puzzle-design`), write them into the brief and get them approved before generating assets. Only the *look* is never copied.
**Encoded in:** `skills/physics-puzzle-design` section 1, `skills/art-direction` (reference rules)
