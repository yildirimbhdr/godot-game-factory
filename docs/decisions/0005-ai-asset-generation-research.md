# 0005 – Game-specific asset generation: options researched (2026-10-21)

Need: assets made for each game's own theme (e.g. screws, characters, items), generated by a service Claude can prompt, inspect
and re-prompt. Prices below are from official pages unless marked unofficial; none was bought or trialled yet.

| Option | Cost (official unless noted) | Strengths | Gaps / risks |
|---|---|---|---|
| PixelLab (official MCP + API) | Free: 40 fast gens then 5/day, sprites up to 200x200, API + MCP + commercial use included. $12/mo: 2,000 gens, 320x320. $24/mo: 5,000 gens, 512x512 | Pixel art only; characters with 4/8 directions, animations, tilesets, transparent map objects, style-consistent generation from a reference | Pixel art style only; some tools use more than one generation per image |
| Gemini image API (direct) | Nano Banana 2.1: $0.0336 per 1K image ($0.0168 batch). 3.1 Flash: $0.067 per 1K | Cheap, general styles, reference images | No documented native transparency (needs background removal step) |
| OpenAI gpt-image-2.5 (direct) | Token pricing: image output $30 per 1M tokens (per-image cost not published as a flat rate; roughly $0.01-0.12, estimate) | Native `background: "transparent"` PNG/WebP, multi-reference edits | Docs warn recurring characters can drift; per-image price needs the calculator |
| Higgsfield MCP | MCP bills credits at standard rates, plan perks (unlimited models) do not apply through MCP. Individual plan prices not readable on the site; unofficial: $15/$39/$99 per month for 200/1,000/3,000 credits, ~2 credits (Nano Banana Pro) to ~8 (GPT Image) per image. Teams from $65/seat | Many models in one place incl. video; OAuth, no key | Middleman price (about 2-10x direct API for the same models); no documented transparent background or consistency tooling; no 3D mentioned on the MCP page |
| Higgsfield API (pay-as-you-go) | Published starting rates $0.0032-0.0059 per image (Soul 2, Marketing Studio Image); failed requests not charged | Cheap, no subscription | Those models are not game-asset models; rates for Nano Banana etc. not seen |
| Ludo MCP | MCP/API needs Pro: $35/mo billed yearly ($420). SFX 2 credits, music 3 | Sprites, animations, SFX, music in one | Commercial rights not stated on pricing page |
| Scenario | $15 / $45 / $75 per month; custom model training from Pro; all paid plans include commercial license | Strongest style lock (train on ~12 reference images) | API/MCP access per plan not stated |

Rough budget for a typical 2D indie game (assumption: ~60 final assets x ~4 attempts = ~240 generations):
Gemini direct ~ $8 (about $4 batch); OpenAI direct ~ $2-30 (estimate); PixelLab $0-12 for the month; Higgsfield MCP ~ $20-100 in credits plus a plan.

Technical needs that matter more than the vendor: transparent PNG, a style anchor (reference images + palette) shared by every asset in a game,
size/resolution control, background removal/trim/downscale, spritesheet slicing, and Claude inspecting each result before accepting it.
